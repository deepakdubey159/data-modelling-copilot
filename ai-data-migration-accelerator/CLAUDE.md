# AI Data Modernization Platform

## Project Vision

Enterprise AI platform that discovers metadata, profiles data, discovers relationships, generates catalogs, business glossaries, conceptual/logical/physical models, DDL, ETL pipelines, migration plans, validation reports and documentation.

## Architecture Principles

- Deterministic engines first
- AI orchestrates engines
- Never duplicate business logic
- SOLID principles
- Typed models
- Pydantic everywhere
- Backward compatibility
- Every module independently testable
- Every module has pytest coverage
- No hardcoded paths
- No vendor lock-in

## Code Rules

- Never refactor working code unless requested
- Never break existing tests
- Prefer composition over inheritance
- Small reusable classes
- Dependency injection where appropriate
